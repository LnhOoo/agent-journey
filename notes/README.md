# 笔记怎么写

不谈文采，只求**留下痕迹**。每天学完花 3 分钟，写三行就够：

```
## 2026-XX-XX  Week N Day M

- 今天学了：<一句话>
- 卡在哪：<具体报错或不懂的概念>
- 明天要做：<一句话>
```

## 为什么要写

1. **写不出「今天学了什么」= 今天其实没学进去。** 写笔记是最便宜的自我检测。
2. 卡住的地方记下来，下次遇到一模一样的问题，你能自己搜到答案。
3. 12 周后这堆笔记就是你面试时最实在的谈资——面试官不爱听"我学过 LangGraph"，爱听"我在这儿踩过一个坑，后来是这么解决的"。

## 文件命名

`YYYY-MM-DD.md`，一天一个文件，放在 `notes/` 下。同一天学了两块内容就写在一个文件里。

## 别忘了提交

每天写完笔记，顺手推一次：

```bash
git add .
git commit -m "notes: 2026-XX-XX 学了 async/await"
git push
```

**这个绿色的提交格子，就是你 12 周的自律记录。**
